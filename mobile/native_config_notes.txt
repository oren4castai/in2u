Native configuration checklist for Phase 2 (foreground location only).

Android (android/app/src/main/AndroidManifest.xml):
- Add inside <manifest> above <application>:
    <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
    <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
    <uses-permission android:name="android.permission.INTERNET"/>
- Do NOT add ACCESS_BACKGROUND_LOCATION in P2.
- minSdkVersion >= 26 (Android 8). Default Flutter template is usually fine.

iOS (ios/Runner/Info.plist):
- Add key NSLocationWhenInUseUsageDescription with string:
    in2u uses your location to find nearby venues and confirm you're inside one.
- Deployment target: iOS 14 minimum.
- Do NOT add NSLocationAlwaysAndWhenInUseUsageDescription in P2.

Background location is NOT used in P2 (heartbeat runs only while app is foreground).

Firebase/FCM push configuration has been removed from this project.
